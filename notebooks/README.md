# Secuencia de notebooks

Los notebooks deben leerse y, cuando se disponga de las fuentes, ejecutarse en orden numérico. `06b` refina el espacio de búsqueda después del HPO temporal de `06`. `08` es el único test final, `09` interpreta sin ajustar y `10` aplica una política operativa separada del modelo. `11` es independiente y exclusivamente descriptivo.

Las salidas se han eliminado de estas copias públicas para evitar rutas personales, mensajes de entorno y duplicación de resultados. Las tablas y figuras necesarias para auditar las conclusiones se encuentran en `../results/`; la aplicación utiliza `../app_data/`.
